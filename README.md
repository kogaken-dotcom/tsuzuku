# 🌱 つづく — 心理学ベースの習慣化 & TODO アプリ

「続けること」そのものが楽しくなるように、行動科学・心理学の知見を組み込んだ Web アプリです。
ビルド不要・外部ライブラリなし（HTML / CSS / JavaScript のみ）。データはブラウザの localStorage に保存されます。

## 使い方

- `index.html` をブラウザで開くだけで基本機能は動きます。
- **PWA（オフライン・ホーム画面・通知）を使うには https で公開**してください（GitHub Pages / Netlify / Cloudflare Pages など。フォルダごと置くだけ）。`localhost` でも動作します。
- 公開したURLをスマホで開き、「ホーム画面に追加」するとアプリとして使えます。
- 機種変更・バックアップは「習慣」タブ下部の **エクスポート / インポート**（JSON）で。

## PWA と通知

| 機能 | 内容 |
|---|---|
| オフライン | Service Worker（`sw.js`）がアプリ本体をキャッシュ。電波がなくても使えます |
| ホーム画面に追加 | `manifest.webmanifest` + アイコン（`icons/`）。Android/PC は「📲 ホーム画面に追加」ボタン、iPhone は Safari の共有 →「ホーム画面に追加」 |
| 習慣リマインダー | 習慣の編集で「⏰ リマインダー時刻」を設定。未完了のときだけ、きっかけ（If-Then）と「2分だけ版」を添えて通知 |
| 通知から記録 | 通知の「✅ やった！」「🐣 2分だけ」ボタンで、アプリを開くと同時に記録されます（Android/PC） |
| 連続記録ピンチ通知 | 前日に休んだ習慣は「🔥 ◯回の連続記録、今日やればキープ！」と添えます |
| ふりかえり通知 | 指定時刻に「今日の勝利数」と残りの習慣数をお知らせ |
| 📅 カレンダー登録 | 習慣の時刻を繰り返し予定＋アラーム付きの `.ics` に書き出し。スマホのカレンダーから**確実に**通知が届きます |

### 通知の届き方（制約）

サーバーを持たない構成のため、通知は次のように届きます。

- **アプリを開いている / バックグラウンドに置いている間**：1分ごとに確認して、時刻どおり通知します。
- **アプリを閉じている間**：ホーム画面に追加した Chrome（Android/PC）では、Periodic Background Sync によりブラウザが判断したタイミングで確認します。数時間単位で遅れたり、届かないこともあります。
- **iPhone**：iOS 16.4 以降で、ホーム画面に追加したアプリから通知を許可できます。閉じている間の通知はほぼ届きません。
- 時刻どおり確実に届けたい場合は **📅 カレンダー登録** を使ってください。完全な時刻指定のプッシュ通知には、Web Push のサーバー（Cloudflare Workers、Firebase Cloud Messaging など）が必要です。

### 更新時の注意

`sw.js` はキャッシュを先に返し、裏で最新版を取りにいきます。そのため、ファイルを更新しても**2回目の起動から**反映されます。大きく変えたときは `sw.js` の `VERSION` を上げてください。

## 画面構成

| タブ | 内容 |
|---|---|
| ☀️ 今日 | 育つ植物、今日の小さな勝利（⭐）、今日の習慣、TODO |
| 🔁 習慣 | 習慣の作成・編集（アイデンティティ / きっかけ / 2分版 / ごほうび / 曜日）、テンプレート、データ管理 |
| 📈 成長 | 通算勝利数、レベル、積み上げカレンダー（ヒートマップ）、週ごとの推移、習慣ごとの記録、バッジ |
| 📝 ふりかえり | 気分 + よかったこと日記、過去ログ、アプリに組み込んだ心理学の解説 |

## 組み込んだ心理学的要素

| 要素 | 根拠 | アプリでの実装 |
|---|---|---|
| タイニー・ハビット | BJ・フォッグ「B = MAP」 | 習慣ごとに「2分だけ版」ボタン。2分版でも連続記録はつながる |
| If-Then プランニング | ゴルヴィツァー（実行意図） | 「〜したら → 〜する」のきっかけを習慣カードに常時表示 |
| アイデンティティ投票 | ジェームズ・クリア | 「読書家に◯票投じました」と“なりたい自分”への票数を表示 |
| 進捗の法則 / スモールウィン | アマビール | 習慣もTODOもすべて「小さな勝利」⭐として可視化、植物が育つ |
| 「2日連続で休まない」 | What-the-hell 効果の回避 | 1日休んでも連続記録は消えない。2日連続で休むとリセット。休んだ翌日は「今日やれば守れる」と表示 |
| 変動報酬 | スキナーの強化スケジュール | 15% の確率で XP 2 倍の「ラッキーボーナス」＋紙吹雪 |
| 目標勾配効果 | Hull / Kivetz | レベル・植物の次段階まで「あと◯XP / ◯勝」を常に表示 |
| 授かり効果（Endowed Progress） | Nunes & Drèze | 初回起動時に +30XP を付与し、最初から少し進んだ状態でスタート |
| フレッシュスタート効果 | Dai, Milkman & Riis | 月曜・月初・3日以上ぶりの再開時に励ましバナー |
| 66日で自動化 | Lally et al. (2010) | 習慣ごとに「自動化まで ◯/66」バーとマイルストーン |
| マイルストーン & 祝福 | フォッグの「セレブレーション」 | 1・7・21・30・66・100・200・365 回で祝福ダイアログとバッジ |
| カエルを食べろ | ブライアン・トレーシー | TODO から「今日の最重要タスク🐸」を1つだけ選べる（XP 2 倍） |
| スリー・グッド・シングス | セリグマン | ふりかえりで「よかったこと」を記録 |
| セルフ・コンパッション | クリスティン・ネフ | 休んだ日を責めない文言（「おかえりなさい」「戻ってきたことが勝利」） |
| 過去の自分との比較 | 時間的比較理論 | 他人とのランキングは置かず、週ごとの推移と「先週同日比」だけを表示 |

## ファイル

- `index.html` — 画面の骨組みとダイアログ
- `styles.css` — デザイン（ライト / ダークモード対応、スマホ優先）
- `app.js` — ロジック（データ・XP・連続記録・描画・演出・通知設定）
- `sw.js` — Service Worker（オフライン・リマインダー通知・通知ボタンの処理）
- `manifest.webmanifest` / `icons/` — PWA 用マニフェストとアイコン
