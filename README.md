# 🌱 つづく — 心理学ベースの習慣化 & TODO アプリ

毎日の小さな「やった！」で、タネが芽を出し、木に育つ。
「続けること」そのものが楽しくなるように、行動科学・心理学の知見を組み込んだ Web アプリ（PWA）です。

**▶ アプリを開く：https://kogaken-dotcom.github.io/tsuzuku/**

ビルド不要・外部ライブラリなし（HTML / CSS / JavaScript のみ）。データは各端末のブラウザ（localStorage）に保存され、外部には送信されません。

## コンセプト：1画面・1タップ・育てるものは1つ

| 画面 | 内容 |
|---|---|
| ☀️ 今日 | 🌱植物と今日のリング、🔥連続日数、今日の習慣（○をタップ）、やること |
| 🌸 きろく | 先週のあなた、スタンプカード、習慣ごとの回数、シール図鑑、ひとこと日記 |
| ⚙️ 設定 | 通知、ホーム画面に追加、やめた習慣、データ、このアプリのしくみ |

はじめて開くと **30秒ガイド**（①続けたいことを選ぶ → ②いつやるか選ぶ → ③今日の分をその場でやる）が始まります。

## 組み込んだ心理学

| 仕掛け | 根拠 | アプリでの形 |
|---|---|---|
| 🐣 小さく始める | タイニー・ハビット（BJ・フォッグ） | 「しんどい日は『1ページだけ』でOK」。ちょっとだけ版でも1回 |
| 🕖 いつやる？ | If-Then プランニング（ゴルヴィツァー） | ガイドで「寝る前」「帰宅したら」などを選ぶ |
| 🎉 最初の1回をその場で | スモールウィン | 習慣を作ったら、すぐ今日の分をやって最初の成功体験 |
| ⭕ 今日のリング | 目標勾配効果・ツァイガルニク効果 | 全部やるとリングが閉じる。「あと1つで満タン！」 |
| 🌱 育つ植物 | 進捗の法則（アマビール） | やるたびに育つ。まだの日は「のどかわいたな…💧」としょんぼり（枯れない） |
| 🎫 お休みチケット | What-the-hell 効果の防止 | 7日続けるごとに1枚（最大3枚）。休んだ日に自動で使われ🔥を守る |
| 🎁 シール集め | 変動報酬（スキナー） | 「やった！」のたびに時々シール。レア・超レアあり。💮の日は必ず1枚 |
| 🌸 スタンプカード | 空欄を埋めたい気持ち | 🌸やった日／💮ぜんぶやった日／🎫チケットで守った日 |
| 📮 先週のあなた | フレッシュスタート効果・過去の自分との比較 | 週はじめに先週の成果と「今週の目標：+1日」 |
| 🧠 66回で体になじむ | Lally et al. (2010) | 習慣ごとに「体になじむまで あと◯回」 |
| 🪪 なりたい自分への1票 | アイデンティティ（ジェームズ・クリア） | 「くわしく設定」で設定すると、きろくに票数が出る |
| 🤝 責めない言葉 | セルフ・コンパッション（ネフ） | 久しぶりに開くと「おかえりなさい！戻ってきたことが一番の勝利」 |

## PWA と通知

- **オフライン**で動作し、**ホーム画面に追加**するとアプリとして使えます。
- 習慣の名前をタップ →「くわしく設定」→ **⏰ 通知する時刻** を設定し、⚙️で通知をオンにします。まだやっていないときだけ通知されます。
- 通知の「✅ やった！」ボタンから、そのまま記録できます（Android / PC）。
- **📅 カレンダーに登録**：時刻を、アラーム付きの繰り返し予定（.ics）として書き出します。確実に通知が欲しいときにおすすめです。

### 通知の制約

- アプリを開いている間、またはバックグラウンドに置いている間は、ほぼ時刻どおりに届きます。
- 閉じている間は、ホーム画面に追加した Chrome（Android/PC）だけが、ブラウザの判断で確認します。遅れたり届かないことがあります。
- iPhone では、閉じている間の通知はほぼ届きません。
- 時刻ぴったりのプッシュ通知には、Web Push のサーバーが必要です。

## ファイル

- `index.html` — 画面の骨組みとダイアログ
- `styles.css` — デザイン（ライト / ダーク対応、スマホ優先）
- `app.js` — ロジック（習慣・連続記録・チケット・シール・描画・通知設定）
- `sw.js` — Service Worker（オフライン・通知・通知ボタンの処理）
- `manifest.webmanifest` / `icons/` — PWA 用

## 更新するとき

`git push` すると、1〜2分で GitHub Pages に反映されます。スマホではキャッシュの仕組み上、**2回目に開いたときから**新しい版になります。大きく変えたときは `sw.js` の `VERSION` を上げてください。
