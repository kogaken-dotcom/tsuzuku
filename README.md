# つづく. — 習慣化 & TODO（積み上げが「目で見える」）

クリアした日が鎖のようにつながり、グラフが右肩上がりに伸びていく。
心理学の知見をもとに「成長が一目でわかる」ことで続けたくなるように設計した Web アプリ（PWA）です。

**▶ アプリを開く：https://kogaken-dotcom.github.io/tsuzuku/**

ビルド不要・外部ライブラリなし（HTML / CSS / JavaScript のみ）。データは各端末のブラウザ（localStorage）に保存され、外部には送信されません。

## できること

| 画面 | 内容 |
|---|---|
| ⚡ 今日 | 🔥連続日数（大きな数字）＋直近14日の「鎖」＋自己ベストまでの距離、🔁毎日のルーティーン（朝・夜などの手順チェックリスト）、今日の進捗バー（習慣ごとに色分け）、習慣ごとの「今週チェーン（月〜日）」、やること（☆で最重要） |
| 💼 仕事 | 今日の日報（数字は自動入力・提出先に送る・連続日数）、目標と期限（KGI・今月の目標・成功の鍵KSF・達成条件・期限・収入）、仮説と検証、面談チェック（フィールド・結果・仮説・良かった点/改善点・FB／フィールド別の成約率）、契約後フォロー、インプット→すぐアウトプット（学び→24時間以内に話す・セミナー日程・アウトプット記録）、ABCセットアップ、週1ふりかえり、KPI（毎日の最低ライン・SMARTチェック）、私の基準 |
| 📈 成長 | 通算・自己ベスト・今月動いた日のタイル、積み上げグラフ（通算クリア数の推移）、週ごとの棒グラフ（先週の同じ曜日と比較）、活動カレンダー、習慣ごとの達成率と次の目標、実績、ひとこと日誌 |
| ⚙️ 設定 | 通知、カレンダー登録、ホーム画面に追加、やめた習慣、データのバックアップ、このアプリのしくみ |

はじめて開くと 30 秒ガイドが始まります。①鍛えたいことを選ぶ → ②いつやるか選ぶ → ③最初の1回をその場でクリア、の3ステップです。

## 見える化のしくみ

- **🔥 鎖**：直近14日、クリアした日が光ってつながる。今日まだなら点滅して「つなげ」と促す
- **今週チェーン**：習慣ごとに月〜日の7マス。どの曜日に抜けたかが一目でわかる
- **積み上げグラフ**：通算クリア数の推移。休んでも下がらないので「ここまで来た」が見える
- **週ごとの棒グラフ**：8週分。今週は「先週の同じ曜日まで」と比べて ▲+N で表示
- **習慣の色**：作った順に固定色（色覚の違いがあっても見分けやすい配色を検証済み）
- **🔁 ルーティーン**：朝・夜・仕事はじめなどの「決まった流れ」を上から順にチェック。「次はこれ」が光り、全ステップ完了で1クリア。テンプレートあり
- **シールド 🛡️**：7日連続ごとに1枚（最大3枚）。サボった日に自動で発動し、連続記録を守る
- **実績**：22種類（通算クリア数・連続日数・パーフェクトデー・タスク数 など）

## 仕事の機能について

- **個人の目標・考え方・お客様の情報は、すべてアプリ内で入力し、その端末のブラウザにだけ保存されます。** プログラムやこのリポジトリには含まれません。
- 今日の画面に「📊 今日の活動量」（最低ラインを＋で記録）と「⚡ 24時間ルール」（気づき→24時間以内、悔しい→今日中、期限切れは赤く表示）があります。
- Notion へは直接書き込めないため、「📋 今日の記録をコピー」→ Notion に貼り付け、の形で記録します。

## 振り返りの考え方（研修の内容から）

- **仮説を持たない実行は浪費**：仮説 → 実行 → 数字で検証 → 改善
- **IOIF**：少しインプットしたらすぐアウトプット。2割できたらやる。失敗前提で試行錯誤
- **日報を毎日、決めた相手に提出**：数字と「仮説と結果・良かった点/悪かった点・明日どうする」
- **フィールド別の数字管理**：どこで出会った人が成約しやすいかを見て、時間の使い方を決める
- **KGI → KSF → KPI**：KPIは自分で100%コントロールできる行動。SMARTで決める
- **自分で完結する予定もスケジュールに**：勉強・連絡まとめ・振り返りのルーティーンテンプレート
- **人脈・知識・技術の積み上げ**：成長タブの3本柱で確認
- **今日の問い**：「株式会社自分」の経営者として考えるための問いを毎日1つ

## 組み込んだ心理学

| 仕掛け | 根拠 |
|---|---|
| 🔥 鎖・今週チェーン | 損失回避：つながった鎖を途切れさせたくない |
| 積み上げグラフ | 進捗の法則（アマビール）：前進の実感がやる気を生む |
| 週ごとの棒グラフ | 競争の熱さを保ちながら、比べる相手は他人ではなく過去の自分（時間的比較） |
| 自己ベスト | スポーツの PB と同じ「記録を塗り替える」達成感 |
| 実績 | ロックされた目標の見える化（目標勾配効果） |
| 今日の進捗バー | ツァイガルニク効果：未完了のものを完了させたい |
| 🔥連続記録 / 🛡️シールド | 損失回避（カーネマン）と、What-the-hell 効果の防止 |
| 🔁 ルーティーン | ハビット・スタッキング（ジェームズ・クリア）：1つ目を始めれば残りが続く。決断疲れも減らす |
| 最低ライン | タイニー・ハビット（BJ・フォッグ）：ゼロの日をなくす |
| いつやる？ | If-Then プランニング（ゴルヴィツァー） |
| 目指す姿 | アイデンティティにもとづく習慣（ジェームズ・クリア） |
| 66回で自動化 | Lally et al. (2010) |

> 注：やる気の出方の男女差は研究上それほど大きくなく、個人差のほうが大きいとされています。このアプリは「達成・競争・記録」で燃えるタイプの人に向けた設計です。

## PWA と通知

- オフラインで動作し、ホーム画面に追加するとアプリとして使えます。
- 習慣の名前をタップ →「くわしく設定」→ ⏰ 通知する時刻。⚙️で通知をオンにすると、まだクリアしていないときだけ通知します。
- 通知の「✔ クリア」ボタンから、そのまま記録できます（Android / PC）。
- **📅 カレンダーに登録**：時刻を、アラーム付きの繰り返し予定（.ics）として書き出します。確実に通知が欲しいときにおすすめです。
- アプリを閉じている間の通知は、ブラウザの判断で遅れたり届かないことがあります（iPhone ではほぼ届きません）。

## 更新するとき

`git push` すると、1〜2分で GitHub Pages に反映されます。スマホでは **2回目に開いたときから** 新しい版になります。大きく変えたときは `sw.js` の `VERSION` を上げてください。
