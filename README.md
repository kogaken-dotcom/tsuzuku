# つづく. — 習慣化 & TODO（積み上げを「数字」と「勝ち負け」で見せる）

毎日のクリアでEXPが貯まり、レベルとランクが上がる。比べる相手は先週の自分。
心理学の知見をもとに「達成感」「記録更新」「競争」で続けたくなるように設計した Web アプリ（PWA）です。

**▶ アプリを開く：https://kogaken-dotcom.github.io/tsuzuku/**

ビルド不要・外部ライブラリなし（HTML / CSS / JavaScript のみ）。データは各端末のブラウザ（localStorage）に保存され、外部には送信されません。

## できること

| 画面 | 内容 |
|---|---|
| ⚡ 今日 | 今日のクリア率（%リング）、LV・ランク・EXPバー、🔥連続日数と自己ベスト、デイリーミッション、習慣（□をタップでクリア）、やること（☆で最重要） |
| 📊 データ | VS 先週の自分、ステータス（通算・自己ベスト・稼働率・パーフェクトデー）、活動カレンダー、習慣別の達成率と自動化までの回数、実績、ひとこと日誌 |
| ⚙️ 設定 | 通知、カレンダー登録、ホーム画面に追加、やめた習慣、データのバックアップ、このアプリのしくみ |

はじめて開くと 30 秒ガイドが始まります。①鍛えたいことを選ぶ → ②いつやるか選ぶ → ③最初の1回をその場でクリア、の3ステップです。

## ゲームのしくみ

- **EXP**：習慣 +10、やること +5、最重要タスク +10。15% の確率で **CRITICAL（2倍）**
- **デイリーミッション**：全習慣クリア +30、やること3件 +15、日誌 +10
- **ランク**：E ルーキー → D チャレンジャー → C ファイター → B エキスパート → A マスター → S レジェンド → SS アンストッパブル
- **シールド 🛡️**：7日連続ごとに1枚（最大3枚）。サボった日に自動で発動し、連続記録を守ります
- **実績**：21種類（通算クリア数・連続日数・パーフェクトデー・タスク数・レベル など）
- **自己ベスト**：連続記録を更新すると通知

## 組み込んだ心理学

| 仕掛け | 根拠 |
|---|---|
| EXP・レベル・ランク | 有能感（自己決定理論・デシ＆ライアン） |
| デイリーミッション | 目標設定理論（ロック＆レイサム）：具体的で達成できる目標 |
| VS 先週の自分 | 競争の熱さを保ちながら、比べる相手は他人ではなく過去の自分（時間的比較） |
| 自己ベスト | スポーツの PB と同じ「記録を塗り替える」達成感 |
| CRITICAL | 変動報酬（スキナー） |
| 実績 | ロックされた目標の見える化（目標勾配効果） |
| %リング | ツァイガルニク効果：未完了のものを完了させたい |
| 🔥連続記録 / 🛡️シールド | 損失回避（カーネマン）と、What-the-hell 効果の防止 |
| 最低ライン | タイニー・ハビット（BJ・フォッグ）：ゼロの日をなくす |
| いつやる？ | If-Then プランニング（ゴルヴィツァー） |
| 目指す姿 | アイデンティティにもとづく習慣（ジェームズ・クリア） |
| 66回で自動化 | Lally et al. (2010) |

> 注：やる気の出方の男女差は研究上それほど大きくなく、個人差のほうが大きいとされています。このアプリは「達成・競争・記録」で燃えるタイプの人に向けた設計です。

## PWA と通知

- オフラインで動作し、ホーム画面に追加するとアプリとして使えます。
- 習慣の名前をタップ →「くわしく設定」→ ⏰ 通知する時刻。⚙️で通知をオンにすると、まだクリアしていないときだけ通知します。
- 通知の「✔ クリア」ボタンから、そのまま記録できます（Android / PC）。
- **📅 カレンダーに登録**：時刻を、アラーム付きの繰り返し予定（.ics）として書き出します。確実に通知が欲しいときにおすすめです。
- アプリを閉じている間の通知は、ブラウザの判断で遅れたり届かないことがあります（iPhone ではほぼ届きません）。

## ファイル

- `index.html` / `styles.css` / `app.js` — アプリ本体
- `sw.js` — Service Worker（オフライン・通知）
- `manifest.webmanifest` / `icons/` — PWA 用

## 更新するとき

`git push` すると、1〜2分で GitHub Pages に反映されます。スマホでは **2回目に開いたときから** 新しい版になります。大きく変えたときは `sw.js` の `VERSION` を上げてください。
